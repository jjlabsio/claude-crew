# 유저 원본 요청

아까 논의한 "레포 내 sandbox 디렉토리 + self-install" 방식으로 claude-crew 플러그인을 이 레포 안에서 자체 E2E 테스트할 수 있는 구조를 만들고 싶다.

핵심 요구사항:
1. 별도 레포 없이 이 레포 안에서 플러그인 스킬/에이전트가 실제 Claude Code 런타임에서 동작하는지 확인 가능
2. npm run 같은 간단한 명령으로 셋업/실행 가능
3. sandbox 디렉토리가 실제 프로젝트처럼 동작해야 함

배경:
- claude-crew는 다른 프로젝트에 설치되어 사용되는 Claude Code 플러그인
- 플러그인 특성상 개발 단계에서 실제 실행 테스트가 어려움
- 현재는 PR 머지 후 다른 레포에서 사용하다가 문제 발견 시 수정하는 비효율적 사이클
- 기존 단위 테스트(vitest)는 CLI sub-command 레벨만 커버, 실제 Claude Code 런타임 통합은 미검증
